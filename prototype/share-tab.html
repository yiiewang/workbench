SDK 配置分析（Java）

/sdk-go/docs/SDK-配置分析-java.md · 最近编辑 2 小时前 · Markdown
右侧不再显示「Select a file from the Explorer to preview」空态：分享管理与文件浏览共用同一个主区，切换 Tab 不打断当前打开的文件。

1. 配置加载顺序

客户端启动时按 chainmaker-sdk-config.yml → 环境变量 → 显式 SdkConfig 的顺序合并配置，后者覆盖前者。

ChainClient client = ChainClient.build(sdkConfig);
client.setAuthType(AuthType.PUBLIC);
client.getChainInfo();   // 连接性自检

2. 关键字段

  • chain_client.org_id：组织标识，必须与证书 OU 一致
  • chain_client.user_key_file_path：签名私钥，支持 PEM / PKCS#11
  • chain_client.node_addr：节点地址，多个节点自动轮询重试
  • archive / rpc_client：归档查询与 RPC 超时参数
